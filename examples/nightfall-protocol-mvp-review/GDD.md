# Nightfall Protocol MVP — GDD Vivo

## Promesa

Un runner móvil completa objetivos bajo presión de un perseguidor sistémico y bots aliados, en partidas cortas offline.

## Core Loop

1. Buscar relay.
2. Reparar mientras el stalker presiona.
3. Reposicionarse o esconderse.
4. Completar todos los relays.
5. Abrir gate y escapar.

## Alcance MVP

- Una arena gris.
- Un jugador.
- Dos bots runner.
- Un bot stalker.
- Tres objetivos.
- Una salida.

## No Incluye

- Multijugador.
- Licencias o contenido parecido a otra IP.
- Monetización.
- Arte final.
